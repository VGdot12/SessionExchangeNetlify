# Upload your session workbook here

Upload your workbook into this folder with the exact filename **sessions.xlsx**.
Commit it to the repository's default branch. GitHub Actions validates it and
updates the production SessionExchange catalogue on Netlify.

Complete the one-time setup in [EXCEL_UPLOAD_SETUP.md](../EXCEL_UPLOAD_SETUP.md)
first. This folder deliberately contains no sample workbook to avoid importing
fictional sessions into your live site.

Only upload data you may place in this repository. In a public repository the
whole workbook and its revision history are public, including unused columns.
You can instead upload a four-column copy: `title`, `room`, `time`, `date`.
